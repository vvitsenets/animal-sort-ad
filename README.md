<p align="center"><b>AI-Assisted Development</b></p>
<p align="center"><b>The project uses AI only as a development assistant. All architecture, integration, and game logic were implemented and adapted within the project.</b></p>
  
  - [x] 1. Nano Banana AI - Used to generate the cartoon-style game background matching the Kenney asset style.
  - [x] 2. Claude 4.8 - Used to assist with creating vector graphics in PixiJS using Bezier curves. Helped design the cartoon-style 3D button with shadows, outline, and glossy highlights.
  - [x] 3. GitHub Copilot - Used for autocomplete suggestions while implementing the game logic.
  
<p align="center"><b>Features</b></p>

  - [x] 1. MVC architecture for clear separation of Model, View, and Controller responsibilities.
  - [x] 2. SOLID principles applied to keep the code modular, maintainable, and extensible.
  - [x] 3. Tutorial screen (TutorialView) with an animated drag-and-drop demonstration.
  - [x] 4. Smooth Drag & Drop interaction with automatic position reset on invalid drops.
  - [x] 5. Hover highlights 🟡 Yellow circle for round animals. 🔷 Light blue square for square animals.
  - [x] 6. Drop zones highlight when a draggable animal is hovered over a valid target.
  - [x] 7. HUD (Hearts (lives) + Flash effect when losing a life).
  - [x] 8. Responsive layout
  - [x] 9. Win / Loss state
  - [x] 10. Custom loadSparrowAtlas() implementation manually parses XML atlases.
